## Mergeon
Lean, distraction-free workspace for multi-author and solo book compilation.  
Author writes, Editor reviews, Mergeon compiles to print-ready PDFs.
    
### Editor Flow 
* Create book
* Add chapters & assign authors
* Review, reorder & preview
* Publish book

### Author Flow 
* Open persistent magic link 
* Write 
* Auto-save 
* Submit for review

#

### System 
- Auth & RBAC
- Chapter state & lockout mode
- PDF template
