## Mergeon
A distraction-free workspace for multi-author documents. Author writes, Editor tweaks, Mergeon compiles high-quality, print-ready PDFs.  

### Editor Flow 
- Create book
- Add chapters, invite & assign authors
- Review, reorder & preview  
- Publish PDF

### Author Flow 
- Write 
- Auto-save 
- Submit for review

#

### System
- Auth & roles 
- Chapter lockout (in review, approved)
- Password-protected magic link
- 1 PDF theme
