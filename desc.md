## Mergeon
Lean, distraction-free workspace for multi-author and solo book compilation.  
Author writes, Editor reviews, Mergeon compiles to print-ready PDFs.
    
### Editor Flow 
* Create book
* Add chapters, set index & assign authors
* Review HTML & compile PDF
* Publish book

### Author Flow 
* Click magic link
* Write 
* Auto-save 
* Submit for review

#

### System 
- Auth & RBAC
- Chapter state (editable, locked)
- Fixed theme

### Stack
- Sveltekit
- TipTap, Typst, Pandoc
- Supabase
